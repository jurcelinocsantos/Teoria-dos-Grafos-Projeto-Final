# Fazenda Nova (GO)

Município que sedia uma importante **Base Descentralizada do SAMU** na porção nordeste da microrregião.

## Estrutura de Atendimento
- Possui **1 Unidade de Suporte Básico (USB)** ativa (CNES 9901825).
- Para ocorrências graves de Código 3 (Vermelho), a USB atua na estabilização primária enquanto aguarda ou realiza *rendez-vous* com a USA enviada de Iporá, conforme o **Protocolo Código Vermelho**.

## Acessos Rodoviários
- **Vindo de Jaupaci/Iporá:** Conectada pelo [[Trecho GO-173 - Jaupaci a Fazenda Nova (28 km)]].
- **Trevo Urbano:** Integra o [[Entroncamento GO-326 x GO-173 (Trevo Fazenda Nova)]].
- **Saída para Novo Brasil:** Eixo pelo [[Trecho GO-326 - Fazenda Nova a Novo Brasil (24 km)]].
- **Saída para Córrego do Ouro:** Eixo pelo [[Trecho GO-326 - Fazenda Nova ao Trevo GO-164 (14 km)]].
