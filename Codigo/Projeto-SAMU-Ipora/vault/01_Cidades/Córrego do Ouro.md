# Córrego do Ouro (GO)

Situado na faixa nordeste da microrregião, conta com rede hospitalar municipal, mas não possui base própria de ambulâncias do SAMU.

## Atendimento de Urgência
- Assistido pela malha regional de urgências.
- Casos gravíssimos acionam o **Protocolo Código Vermelho**, mobilizando a USA-01 a partir de Iporá num trajeto de 104 km.

## Acessos Rodoviários
- **Entrada Principal:** Recebe o [[Trecho GO-164 - Trevo GO-326 a Córrego do Ouro (18 km)]].
- **Acesso Viário:** Integração com o **Entroncamento GO-326 x GO-164**.
